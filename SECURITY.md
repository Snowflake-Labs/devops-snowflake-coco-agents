# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
responsibly. **Do not open a public GitHub issue.**

Send details to [security@snowflake.com](mailto:security@snowflake.com) or
use Snowflake's responsible disclosure program at
<https://hackerone.com/snowflake>.

We will acknowledge receipt within 3 business days and provide a timeline
for a fix.
